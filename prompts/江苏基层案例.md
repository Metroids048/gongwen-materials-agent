# 江苏基层创新案例送审稿

本轮按征集启事编写经验材料，profile 用 experience-draft。只返回以下五节，标题逐字一致并按此顺序：内容提要、案例背景、主要做法、成效与影响、经验启示。正文的主力是“主要做法”，按意见进来、有人议、如何办与反馈交代机制，优先写可观察的分工、过程和结果。启示提炼可复用动作及适用条件，不代写实际推广成效。总标题直接点题。申报单位由宿主按要求留待确认，正文不要加该行或盖章页。

内容提要写约240字，背景约450字，三个正文小节合计不超过3000字，按中文字符（含标点、除空白）预估。篇幅不足可解释已有事实之间的关系、写清实际工作场景和具体角色，不能补造过程、因果、时点或成效。每个 paragraphs 条目是单个自然段，段内无换行。各节可有多段。地名、事项、时点、指标和计量单位按材料写。即使来源提供范围限制，也把边界融入表述；把尚无证据的事放待核。材料中的 URL 仅用于人查证，不需要复制到稿内。

以下上游文件只提供写法。只参考做法段的组织、如何从真实堵点进入动作、如何从个案提取复用条件。示例内事实、名称、数字、引用和语料样本的统计值没有本案依据，一律不进稿。上游的结构权重是参考，江苏征集通知的五节与篇幅优先。

只在材料用途清单中登记后面 JSON 数组中带 id 的本轮输入，一项一个 ID。上游文件属于提示的一部分，不能作为 material_uses 条目。材料已足够生成供核稿的全文，申报单位等未决事项写入 review_notes。返回完整标题和五节正文，每段的 anchors 仅用后面输入实际存在的编号。
