# Official Document Writing and Review Team

The existing workflow selects specialists by document type and binds every handoff to the same task. Use the existing authorized template and original-revision entries for those tasks. Simple text-only notices can use the single draft and program checks. Use the fuller team for complex or attachment-based work.

1. For separate source texts or attachments, the [source and outline specialist](references/素材与框架.md) prepares a short source sheet and outline, with anchors for known and unresolved items.
2. The [writer](../gongwen-expert/SKILL.md) reads the user's words and original sources directly. Draft the prose and any required task table. Use verified public evidence or deterministic calculations supplied by the host. Run program checks and use the existing repair path for correctable findings. Ask once if a missing decision materially changes a usable draft.
3. The [independent reviewer](../gongwen-expert-review/SKILL.md) checks the same candidate and sources. Inspect the actual assignment cells and responsibility in a plan, attribution and results in experience writing, and each session's requirements in a notice. In assistance/delegation consultations, check both intake alternatives, the pending ordinary-closure form, and the blank discussion result cells. Apply targeted fixes and export through the same Word entry.

Bind the source sheet to the current input and review to the checked candidate. If a source brief is unavailable, the writer can use the original sources directly. If review is incomplete, use the host's delivery state and describe remaining business decisions without internal identifiers. A draft can accompany pending review when the delivery state allows it. Approval requires human confirmation.
