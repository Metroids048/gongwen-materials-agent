# Reviewing Work Plans and Pre-Meeting Papers

The source brief identifies evidence, roles, and pending decisions. The writer starts with what needs deciding, then develops matching prose and task rows. The reviewer compares the same action, owner, timing, deliverable, status, headers, cells, and attachments. Keep pending matters provisional.

Trace intake, authorization, filing, feedback, and archiving. Target an existing row for a gap within that action. Use `TASKS` only when an independent action is missing. For handoffs, check sender, receiver, evidence, completion, retention, and any prerequisite to verification or acknowledgment in the actual table. If an operational row is missing an established handoff record present only in a retention row, target the operational row as `blocking` and add the same evidence-backed deliverable. For exceptions, check recording, review, support, closure conditions, and where the result goes. Leave an unspecified filer open. Trace how the first report travels and who confirms it.

Use true sequencing in the dependency column. Do not turn parallel responses to the same event into approval gates. A list provided for use is not necessarily the only configuration basis. Use adjacent sources for upstream and downstream relationships. Put a known confirmation result in its deliverable even if the record format is unknown. Target the precise T row if it is missing.

If the source requires a published or updated delegated-service list, check for a separate preparatory task and the published list as its deliverable. If the row is missing, target `TASKS` and propose it with undecided lead and date open. Intake checks, prose, or comparison rows do not cover preparation. Also retain all ordinary processing tasks.

In the actual 「帮办与代办情形对照」 table, check the submitting party, voluntary delegation, list and preliminary review, signing and registration, tracking, feedback, and closure. Check both outcomes in the 「事项范围与材料预审」 row's 「判定与下一步」 cell: self-filing guidance for out-of-list matters, and delayed signing with correction and repeat review for failed preliminary review of in-list matters. Report a missing option as a targeted P-row `blocking` finding with the original anchor. Keep the full-width delimiter and original column count when correcting.

Check that the Word discussion table contains each undecided item with its original wording and an actionable discussion prompt, with decision cells blank. When multiple units must decide separately, use adjacent 「议题原名（单位原名）」 rows and one decision cell per unit. If they share one row, target it and cite the instruction to separate them. Preserve all criteria for dates. Distinguish criteria for setting a date, preparatory work, and launch prerequisites. Keep undecided leads, staff, counters, and dates open.

Distinguish ordinary closure from early termination. Without evidence that both require the same form, only assign the form to early termination. Keep the pending question 「正常办结是否需填写代办委托终止单，待核」 in the ordinary-closure prose and actual task deliverable. The question itself is pending. The omission of the explicitly needed notice is a targeted `blocking` correction. Preserve established deliverables and sequencing even when responsibility or dates are open.
