# Pre-Delivery Check

Before delivery, check the actual prose and Word assignment table separately.

- Split established requirements from matters still for decision. Put a required training, service, or reporting action in its own anchored `fact` paragraph, even if timing, organizers, or standards are unknown. Use `proposal` for suggested arrangements. An opening discussion question does not replace the later statement of an established requirement.
- If the user asks for a task table, include both action-level responsibilities and overall implementation duties. List any cross-level or joint implementation duty on its own line, with the appropriate units in `lead` as 「共同负责：」 or 「责任单位：」. Do not turn them into leads for every subtask.
- If the user requests records, submission, or confirmation of training completion and the source establishes only the training obligation, keep that obligation and state which deliverable format, submission, or acceptance decision remains open.
